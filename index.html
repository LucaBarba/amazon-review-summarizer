Multi-model benchmark for Amazon review summarization

Comparing five abstractive Seq2Seq models against an extractive TF-IDF baseline across 400 products, evaluated with ROUGE, BERTScore, and sentiment alignment.

View on GitHub Download Notebook

How it works

End-to-end pipeline

The pipeline streams the Amazon Reviews 2023 dataset, selects 400 products from the Toys & Games category, and runs each product through 8 review groups (overall, positive, negative, and each star rating) across all models. Every result is saved incrementally so the pipeline resumes automatically if interrupted.

01

Product Selection

400 products sampled from the BarbaDLuca/amazon-reviews-2023-with-asin dataset via HuggingFace streaming. Fixed seed ensures reproducibility.

02

Review Grouping

Each product's reviews are split into 8 groups: overall, positive (4–5 stars), negative (1–2 stars), and individual star ratings.

03

TF-IDF Medoid Selection

For each group, the 15 most representative reviews are selected via TF-IDF cosine similarity, mitigating the Lost in the Middle problem.

04

Silver Reference Generation

Qwen2.5-1.5B-Instruct runs locally in FP16 to generate neutral consensus summaries used as pseudo-ground-truth references.

05

Multi-Model Summarization

All 6 models (5 abstractive + 1 extractive baseline) generate summaries with beam search (4 beams), length penalty, and n-gram repetition blocking.

06

Evaluation

ROUGE, BERTScore (batched, single model load), and VADER sentiment alignment computed across all 400 products and 8 groups.

Models

What was benchmarked

Five fine-tuned Seq2Seq summarization models from different training domains, one extractive baseline, and one LLM-generated silver reference.

Abstractive
philschmid/bart-large-cnn-samsum

BART-SamSum

BART fine-tuned on SAMSum dialogue dataset. Best overall performer — dialogue training transfers well to informal review text.

Abstractive
facebook/bart-large-cnn

BART-CNN

BART fine-tuned on CNN/DailyMail news. Strong baseline with formal, structured output.

Abstractive
sshleifer/distilbart-cnn-12-6

DistilBART

Distilled version of BART-CNN. Competitive performance at ~60% of the size.

Abstractive
google/pegasus-cnn_dailymail

PEGASUS-CNN

PEGASUS fine-tuned on CNN/DailyMail. Lowest performer — gap-sentence pretraining optimized for news compression transfers poorly to reviews.

Abstractive
Falconsai/text_summarization

Falconsai

Compact general-purpose summarizer. Best sentiment alignment despite being the smallest model — preserves opinion polarity effectively.

Extractive
TF-IDF Medoid

TF-IDF Baseline

Selects 3 most representative sentences via cosine similarity. No generation — preserves original wording and sentiment faithfully.

Silver Reference
Qwen/Qwen2.5-1.5B-Instruct

Qwen2.5-1.5B

Instruction-tuned LLM used to generate neutral consensus summaries as pseudo-ground-truth. Runs locally in FP16 on GPU.

1

Training domain matters more than model size

BART-SamSum leads on ROUGE and BERTScore despite being architecturally identical to BART-CNN. Dialogue fine-tuning transfers better to informal review text than news fine-tuning.

2

Extractive models preserve sentiment better

TF-IDF (0.955) and Falconsai (0.958) outperform larger abstractive models on sentiment alignment. Abstractive models smooth over strong opinions — a phenomenon called abstractive smoothing.

3

BERTScore gaps are narrow; ROUGE gaps are wide

All models score within 0.022 BERTScore F1 of each other — they understand the content similarly. But ROUGE-2 varies 2.5x between best and worst, reflecting strong stylistic differences in word choice.

4

PEGASUS is the clear outlier

Trained for extreme compression on news, PEGASUS produces the lowest scores across all metrics. Gap-sentence pretraining does not generalize to multi-document opinion summarization.

Evaluation

How summaries are measured

Reference-based

ROUGE-1 / 2 / L

N-gram overlap between the generated summary and the Qwen silver reference. Strict lexical metric — penalizes paraphrase.

Reference-based

BERTScore F1

Semantic similarity via RoBERTa-large embeddings. Understands that "good" and "excellent" are similar — less sensitive to wording variation than ROUGE.

Reference-free

Sentiment Alignment

VADER classifies the majority polarity of source reviews and the summary. Measures whether the model preserves the overall opinion direction.

Getting started

Run it locally

Requires Python 3.11, a CUDA-capable GPU (6 GB+ VRAM recommended), and a HuggingFace account to access the dataset.

1. Clone the repository

git clone https://github.com/LucaBarba/amazon-review-summarizer
cd amazon-review-summarizer

2. Create and activate the virtual environment

# Windows PowerShell
python -m venv amazon_env
.\amazon_env\Scripts\activate

# macOS / Linux
python3.11 -m venv amazon_env
source amazon_env/bin/activate

3. Install dependencies

# PyTorch with CUDA 12.1
pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

# Core dependencies
pip install transformers==4.52.4 datasets==2.20.0 accelerate sentencepiece tiktoken
pip install scikit-learn==1.3.2 nltk pandas==2.1.4 numpy==1.26.4 tqdm
pip install rouge-score bert-score
pip install ipykernel notebook

# Register kernel
python -m ipykernel install --user --name=amazon_env --display-name "Python (amazon_env)"

4. Launch and run

python -m jupyter notebook

Open amazon_review_summarizer_local.ipynb, select the Python (amazon_env) kernel, paste your HuggingFace token into Cell 3, and run all cells sequentially.

Hardware requirements

Tested on an NVIDIA GTX 1660 Ti (6 GB VRAM). All models load in FP16. Expected runtime for a full run across all 400 products and 5 models: approximately 4–6 hours.
